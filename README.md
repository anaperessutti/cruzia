# OLA! Costa Beneficios

Vamos a crear OLA!, una WebApp de cupones y beneficios locales para el Partido de la Costa (Argentina), mobile-first, con diseño premium/aspiracional. Stack: React + Tailwind CSS, Supabase como backend. Todavía no generes pantallas ni esquema de base de datos — en el próximo mensaje te voy a dar el modelo de datos completo y las reglas de negocio.
